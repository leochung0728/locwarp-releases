# LocWarp

**LocWarp** 是一款桌面工具，可在你自己的 iPhone 上模擬 GPS 位置——瞬移到指定座標、沿路線以真實速度移動、用搖桿自由走動，支援 Windows 與 macOS。

> ⚠️ 本工具僅供你在**自己擁有、已授權**的裝置上測試與開發使用。請遵守 App 與服務的使用條款及當地法令。

## 🔑 需要授權才能使用

LocWarp 需要一份**授權檔（`.lwlic`）**才能啟用。第一次開啟時會顯示鎖定畫面與你這台電腦的「機器碼」：

1. 把畫面上的**機器碼**複製給授權發放方（本工具作者）。
2. 收到 `.lwlic` 授權檔後，在鎖定畫面點「匯入授權」選擇該檔即可解鎖。
3. 授權綁定這台電腦、可設到期日；換電腦需重新申請。

> 沒有授權檔也可以安裝，但功能會被鎖住。取得方式請聯絡提供這支程式的人。

## 🚀 快速上手

1. 用傳輸線把 iPhone 接上電腦，手機點「信任這台電腦」。
2. 依指示在 iPhone 開啟**開發者模式**（iOS 16 以上）。
3. LocWarp 偵測到裝置後會自動完成配對；在地圖上點一下目標位置 → 按**瞬移**。
4. 想沿路線移動，就建立路線並按**播放**。

完整功能教學請看 **[使用教學 → docs/USAGE.md](docs/USAGE.md)**。

## ❓ 常見問題

- **接了線卻偵測不到手機？** 先在手機點「信任」，並確認已開啟開發者模式；詳見安裝教學的疑難排解。
- **拔線後想用 Wi-Fi 連？** 需先用傳輸線完成一次配對，並在 iPhone 設定開啟「在 Wi-Fi 顯示此 iPhone」。
- **macOS 說「無法打開，因為無法驗證開發者」？** 到「系統設定 → 隱私權與安全性」按「仍要打開」，見安裝教學。
