## 連線裝置

1. 用傳輸線接上 iPhone（或已設定好的 Wi-Fi 連線）。
2. LocWarp 會列出偵測到的裝置，顯示型號、iOS 版本與連線方式（USB／Wi-Fi）。
3. 狀態變成 **就緒** 即可操作。若顯示需要信任或開發者模式，請依安裝教學處理。
4. 按 **中斷** 可停止控制該裝置；之後它再出現時可一鍵重新連線。

> 可在設定決定是否「偵測到信任過的 iPhone 時自動連線」，或改成每次手動連。

## 瞬移到指定位置

把位置瞬間設定到任一座標：

- **在地圖上點一下** 目標點，按 **瞬移**；或
- 在搜尋框輸入**地址／地名**查詢後選取；或
- 直接**貼上座標**（支援十進位、度分秒、Plus Code 等格式，可在設定切換顯示）。

> **冷卻提醒**：短時間內把位置拉得太遠，iOS 會有一段「冷卻」時間才接受新位置。LocWarp 會提示需要等待的距離與秒數，耐心等一下即可。
> **中國大陸座標**：貼上疑似大陸範圍的座標時，可選擇把 GCJ-02 偏移修正回 WGS-84（設定可關閉提示）。

## 沿路線移動（播放）

模擬「一邊走一邊移動」的軌跡：

1. 進入**路線編輯**，在地圖上依序點出途經點，或匯入 GPX。
2. 選**移動方式**：步行 / 單車 / 開車 / 直線。前三者會沿道路規劃路徑。
3. 設定**速度**與**循環方式**：
   - 單次（once）：走完停。
   - 循環（loop）：到終點後從頭再走。
   - 來回（pingpong）：到終點後倒著走回來。
4. 可開啟**擬真**選項讓軌跡更自然：速度抖動、GPS 微抖動、轉彎減速、途中停留（dwell）。
5. 按 **播放**。播放時可看到目前位置、已走距離、速度、預估剩餘時間，並可暫停／繼續／停止。

## 搖桿自由走動

想即時手動控制方向：

- **搖桿模式**：用畫面上的搖桿控制前進方向與速度，像走路一樣即時移動；可選慣性與 GPS 微抖動。
- **漫遊模式（wander）**：設定一個中心點與半徑，讓位置在範圍內自然地走走停停。

走動過程可**錄製軌跡**，事後存成路線重複使用。

## 收藏位置與路線

常用的點與路線可存成**收藏**：

- 收藏可命名、加備註、**分類**、對地點**評分**（0–10）。
- 列表可依名稱、距離、時區、評分等排序與篩選、搜尋。
- 支援**匯出／匯入**（JSON／CSV／GPX），方便備份或分享給另一台電腦。

## 多機群組

同時控制多支 iPhone，讓它們**一起移動並保持隊形**：

1. 建立群組，指定一台為 **領頭（leader）**，其餘為 **成員（member）**。
2. 選**隊形**：堆疊 / 並排 / 縱列 / 跟隨，並設定**間距**與**跟隨延遲**。
3. 對領頭做瞬移或播放路線，成員會依隊形跟著移動。

> 某些成員當下沒有連線時，只會略過它，不會算成「同步失敗」。

## 自動化排程

讓動作在指定時間自動執行：

- **觸發方式**：每日固定時間（可選星期）、固定間隔（可設時段）、或單次指定時間。
- **動作**：瞬移、播放路線、漫遊、還原真實位置、停止。
- 可設定**隨機延遲**讓時間不要太規律，動作結束後可選擇自動還原。
- 會記錄每次執行結果（成功／略過／錯誤）。

---

## 還原真實位置

結束模擬、讓 iPhone 回到真實 GPS：

- 按 **還原**，或在設定開啟「**結束程式時自動還原**」。
- 也可把「還原」設成自動化動作，在排程結束時自動執行。

> 若模擬位置沒有立刻消失，重開手機上該 App 的定位、或重新啟動 iPhone 即可。

## 設定

**設定** 頁可調整：

- **座標格式**：十進位 / 度分秒 / Plus Code。
- **提示**：中國大陸座標校正提示、冷卻提示。
- **地圖圖磚與版權**：可換成自架或其他圖磚服務。
- **路徑規劃（OSRM）與地址查詢（Geocoder）**：可指定自架服務網址。
- **自動連線**：偵測到信任過的 iPhone 時是否自動連線；是否自動開啟 Wi-Fi 顯示。
- **結束時自動還原**。
- **本機 API**：是否接受本機的 CLI／腳本（進階）。
- **授權資訊**：檢視客戶名稱、到期日、機器碼、已授權功能，或**更換授權檔**。
- **診斷**：一鍵檢查環境與連線，回報問題時很有用。
