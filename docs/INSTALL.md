## 一、下載

到 **[Releases 頁面](../../releases/latest)**，依系統下載：

| 系統 | 檔案 |
|------|------|
| Windows 10/11（64 位元） | `LocWarp Setup x.y.z.exe` |
| macOS（Apple Silicon，M1 以上） | `LocWarp-x.y.z-arm64.dmg` |

> macOS 目前提供 Apple Silicon（arm64）版。Intel Mac 不在支援範圍。

---

## 二、Windows 安裝

1. 雙擊下載的 `LocWarp Setup x.y.z.exe`。
2. 若跳出藍色視窗 **「Windows 已保護你的電腦」（SmartScreen）**：
   - 這是因為安裝檔未做商業簽章，屬正常現象。
   - 點 **「更多資訊」** → **「仍要執行」** 即可繼續。
3. 依精靈完成安裝，桌面／開始功能表會出現 LocWarp。
4. 第一次開啟若被防毒軟體攔，請把 LocWarp 加入信任／例外。

> 解除安裝：Windows「設定 → 應用程式」找到 LocWarp 移除即可。

---

## 三、macOS 安裝

1. 雙擊下載的 `LocWarp-x.y.z-arm64.dmg`。
2. 在開啟的視窗中，把 **LocWarp 圖示拖進「應用程式（Applications）」** 資料夾。
3. 到「應用程式」開啟 LocWarp。第一次開啟可能會被 macOS 的 Gatekeeper 攔下，分兩種狀況：

   **狀況 A — 「無法打開 LocWarp，因為無法驗證開發者」**
   - 方法 1：在「應用程式」對 LocWarp 圖示 **按右鍵 → 打開**，再按一次 **「打開」**。
   - 方法 2：到 **系統設定 → 隱私權與安全性**，往下找到被阻擋的 LocWarp，按 **「仍要打開」**。

   **狀況 B — 「LocWarp 已損毀，無法打開，你應該將其丟到垃圾桶」**
   - 這其實不是真的損毀，而是下載檔被加上「隔離（quarantine）」標記。**右鍵打開通常無效**，要用指令清除標記。
   - 開「終端機」（應用程式 → 工具程式 → 終端機），貼上這行後按 Enter（會要你輸入開機密碼，打字不會顯示是正常的）：
     ```
     sudo xattr -dr com.apple.quarantine /Applications/LocWarp.app
     ```
   - 完成後再開啟 LocWarp 即可。

   > 以上都是因為 App 未做 Apple 公證（notarization），屬正常現象，處理一次即可。
4. 若系統要求，允許 LocWarp 存取與 iPhone 連線所需的權限。

> 解除安裝：把「應用程式」裡的 LocWarp 拖到垃圾桶即可。

## 四、iPhone 端設定（必做）

LocWarp 透過 Apple 的開發者介面與 iPhone 溝通，手機端需要兩個前置動作：

### 1. 信任這台電腦
用傳輸線把 iPhone 接上電腦，手機會跳出 **「要信任這台電腦嗎？」** → 按 **「信任」** 並輸入螢幕鎖密碼。

### 2. 開啟開發者模式（iOS 16 以上）
1. iPhone **設定 → 隱私權與安全性 → 開發者模式**。
2. 打開開關，手機會要求 **重新開機**。
3. 重開後會再問一次是否啟用開發者模式 → 選 **「開啟」** 並輸入密碼。

> - 找不到「開發者模式」選項？先用傳輸線接上電腦並開啟一次 LocWarp，該選項通常就會出現；或重開機後再找。
> - iOS 15 以下不需要開發者模式，接線信任即可。

完成後回到 LocWarp，程式會自動偵測並完成配對，裝置狀態顯示為「就緒」。

## 五、匯入授權

LocWarp 需要授權檔（副檔名 `.lwlic`）才能啟用（整支程式都會被授權保護）。

1. 第一次開啟會看到**鎖定畫面**，上面有這台電腦的 **機器碼（machine code）**。
2. 點 **「複製機器碼」**，把它傳給授權發放方（提供這支程式的人）。
3. 收到 `.lwlic` 檔後，回到鎖定畫面點 **「匯入授權」**，選擇該檔。
4. 驗證通過後即解鎖；你可在 **設定 → 授權資訊** 看到客戶名稱、到期日、機器碼與功能。

### 更換授權
到 **設定 → 授權資訊 → 更換授權檔**，選新的 `.lwlic` 匯入即可（例如續期、擴充功能）。

> **注意事項**
> - 授權**綁定這台電腦**。換電腦或重灌後機器碼會變，需重新申請。
> - 授權可設**到期日**，到期後需換新檔。
> - 本工具不會連網驗證授權（離線驗證），但會偵測系統時間被往回調整的情形。

## 六、用 Wi-Fi 無線連線（選用）

想拔掉傳輸線、改用同一個 Wi-Fi 連線：

1. 先用**傳輸線**完成一次「信任 + 配對」（見第四節）。
2. 連著線時，在 LocWarp 把該裝置的 **「在 Wi-Fi 顯示此 iPhone」** 打開
   （或在設定開啟「偵測到信任過的 iPhone 時自動連線」，並讓 App 幫你開 Wi-Fi 顯示）。
3. 確認電腦與 iPhone **在同一個 Wi-Fi 網段**。
4. 拔掉傳輸線，LocWarp 應能透過 Wi-Fi 重新連上同一台 iPhone。

> iOS 17／iOS 26 等新系統對無線連線較嚴格；若 Wi-Fi 連不上，先接回傳輸線重做一次配對，再試一次。

## 七、疑難排解

| 狀況 | 處理方式 |
|------|----------|
| 接了線卻偵測不到 iPhone | 手機點「信任這台電腦」；確認已開啟開發者模式並重開機；換一條**原廠傳輸線**、換 USB 埠。 |
| 一直停在「配對中 / 需要信任」 | 解鎖手機螢幕，重新插拔傳輸線，手機出現對話框時按「信任」。 |
| 顯示「需要開發者模式」 | 依第四節開啟並重開機。 |
| 瞬移後 App 位置沒更新 | 部分 App 會快取位置；在該 App 內重新整理，或關掉重開定位。 |
| macOS 說「無法驗證開發者」 | 右鍵→打開，或系統設定→隱私權與安全性→仍要打開；見第三節狀況 A。 |
| macOS 說「已損毀，應丟到垃圾桶」 | 用 `sudo xattr -dr com.apple.quarantine /Applications/LocWarp.app` 清除隔離標記；見第三節狀況 B。 |
| Windows 被 SmartScreen／防毒攔 | 見第二節；把 LocWarp 加入信任。 |
| Wi-Fi 連不上 | 先用傳輸線完成配對，確認同一 Wi-Fi 網段；見第六節。 |
| macOS 卡在「掛載開發者映像檔」，出現 `Permission denied … .pymobiledevice3` | 多半是之前用 `sudo` 跑過相關工具，把資料夾變成 root 擁有。開「終端機」執行：`sudo chown -R "$(whoami)" ~/.pymobiledevice3` 後回 App 按「重試」。 |
| 授權匯入失敗 | 確認 `.lwlic` 是**發給這台電腦機器碼**的、未過期；系統時間未被往回調；重新向發放方索取。 |

還是不行的話，把 **設定 → 診斷** 的結果，連同你的系統版本與 iOS 版本回報給提供這支程式的人。
